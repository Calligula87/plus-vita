# Plus-Vita v001 - unreleased

v001 is the planned next public version after v000. This is a staging record,
not a release announcement or a request to build another VPK.

## Current development baseline

The maintainer accepted the currently tested result on 2026-11-04. Implementation
commits `d8f2709` and `73fb17a` are local on `main`, on top of the earlier
control work. The tested package and hash are recorded in
[scrolling/menu acceptance](SCROLLING_MENUS_TEST.md).

Changes saved for the next version:

- One saved gameplay layout with remapping, Disabled, defaults and fixed menu
  controls/physical exit (#37).
- D-pad/stick navigation, touch-release activation/cancellation and short screen
  transitions (#39).
- Continuous control-mapping lists, drag scrolling, clamped focus and proportional
  position indicators (#41).
- Shared list behavior throughout ordinary app menus (#42).
- Seven-row title catalogue with a fixed cover preview after three settled
  seconds, shared bounded cache, cancellation/retry and retained browsing state
  through details/Play (#43; parent #40).

PS TV controller implementation is present, but actual DualShock 3 and DualShock 4
hardware acceptance remains open in #38. Do not claim verified compatibility
until those device-specific checks are reported.

## Release hold

The maintainer explicitly requested no push and no new VPK release yet; more
changes may be added. Commit acceptance and staging documentation locally only.
Do not create a tag, release, upload a replacement VPK, or publish source as part
of this acceptance. The already tested development package remains preserved.

Published version v000 and its accepted artifact remain unchanged. The current
public build configuration still says v000 / numeric Vita revision `00.11`.
When a future v001 release is authorized, plan visible/diagnostic identity v001
and numeric revision `00.12` (a separate update-install revision), then update
build/export/gate expectations together. No version constants are bumped now.
A future public package must use the anonymous committed-source release process
and pass its package/privacy gates; the tested development VPK is not a public
release artifact.
